# HNG To-Do App

A full-stack to-do list built with React (Vite), Express and Supabase.

Features: create, edit, delete and complete tasks; notes on each task; priority (low/medium/high); search; filter by status and priority; reorder tasks.

Built entirely with AI assistance (Claude).

## Run locally
1. `cd backend`, create `.env` with SUPABASE_URL and SUPABASE_SERVICE_KEY, then `npm install` and `npm run dev`
2. `cd frontend`, create `.env` with VITE_API_URL=http://localhost:5000, then `npm install` and `npm run dev`
